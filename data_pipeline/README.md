# Data Pipeline

## Objective

Build an end-to-end data pipeline using books.toscrape.com.

## Tasks

1. Scrape book data using Python, Requests, and BeautifulSoup.
2. Collect at least 60 books from at least 3 categories.
3. Clean and transform the scraped data.
4. Convert GBP prices to INR using the fixed rate:
   `1 GBP = 105.50 INR`
5. Store the cleaned data in a normalized SQLite database.
6. Execute SQL queries demonstrating filtering, sorting, limiting, distinct values, range/category filtering, and joins.
7. Compare SQL results with equivalent pandas operations.

## Technologies

- Python
- Requests
- BeautifulSoup
- Pandas
- SQLite
- SQL
